# Data-for-Enhancing-Infrared-Laser-Dissociation-of-Molecules-with-the-Electromagnetic-Vacuum-
Code and data used in "Enhancing Infrared Laser Dissociation of Molecules with the Electromagnetic Vacuum", by Johan Triana and Felipe Herrera - Published in Phys. Rev. Lett. at https://doi.org/10.1103/s2zc-6lxs -  Preprint at https://arxiv.org/abs/2511.17278. 

Repository Contents: 

- Figure 2 Data
- Figures 3a and 3b Data
- Figures 4a and 4b Data
- MCTDH Input and Operator files for Figure 4a (ED=0.03 aJ).
